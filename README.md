# Project Abstract
The Car Rental Fleet Manager is a Java-based system designed to help rental businesses manage their vehicle fleet, bookings, and billing in a simple and organized way. The system allows staff to maintain the list of available vehicles, register customer bookings, and track the status of each car as available, booked, or under maintenance. It also provides an efficient billing module that automatically calculates the rental charges based on the number of days and vehicle category, reducing manual calculation errors and saving time. The project uses basic concepts of Java Programming such as classes, objects, methods, arrays, loops, conditional statements, and File Handling to manage vehicle records and booking data effectively. With its simple and User-Friendly System design, the project improves coordination between staff and customers while supporting Automation of routine fleet management tasks. The main aim of the project is to provide a simple, accurate, and efficient solution for Car Rental Fleet Management while giving students practical knowledge of Java Programming and its application in solving reallife problems.
